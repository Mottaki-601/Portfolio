OPTIONAL PROJECT SCREENSHOTS

The portfolio works without project cover banners. It automatically renders a matching CSS-made preview for every project.

If you have a screenshot of your actual app, save it using one of these names:
- nexora-suite.jpg
- tour-management.jpg
- restaurant-management.jpg

Put the files in this folder. PNG and WebP are also supported, but if you use another extension, update the matching data-cover-src value in index.html.

All screenshots are displayed in the same 16:9 frame with object-fit: cover, so screenshots with different dimensions still align with the design. Keep original screenshots at 1200px wide or larger where possible. Do not create a special banner just for the portfolio.
